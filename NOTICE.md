# PhoneCheck phone data

This release contains an automatically generated database of phone model codes (TAC) and model names,
used by the PhoneCheck app. It is rebuilt monthly from:

* **Osmocom TAC database** (http://tacdb.osmocom.org/), licensed **CC BY-SA 3.0**.
* **Community TAC list** (https://github.com/MoazEb/tac-database), labelled MIT; it states that it was compiled
  from other sources. Entries are unverified and may be wrong or incomplete.

Names were normalized. Because Osmocom data is CC BY-SA 3.0, this adapted database is published here under
the same license (CC BY-SA 3.0). PhoneCheck is independent and not affiliated with GSMA, manufacturers or carriers.
